# 📊 Sales Snapshot – SQL Data Analyst Project

This is a real-world-style data analyst project where I use SQL to explore sales data, answer business questions, and deliver meaningful insights through grouped queries, summaries, and visuals.

---

## 🧠 Business Use Case

> “We need a quick snapshot of sales. What’s selling best this quarter? Which regions are performing the strongest?”

This project answers that question by querying and analyzing sales data, organizing findings by product, region, and time.

---

## 🛠️ Tools Used

- **SQL** – Data exploration, cleaning, grouping
- **GitHub** – Version control and documentation
- **Trello** – Project planning and task tracking
- **Screenshots** – Captured at key milestones (see `/images/`)

---

## 📁 Project Structure

- sql queries/ → SQL files used for querying and analysis

- images/ → Screenshots captured at key milestones

- outputs/ → Final results (e.g. Excel summaries or exported tables)
